LEGEND:
─────────────────────────────────────────────────────────────────────────────────
🎯 Planning Team      - Creates and refines project plans
💬 Answer Team        - Provides answers to AI-assisted questions  
🔨 Decomposition Team - Breaks down complex tasks into subtasks
✅ Verification Team  - Validates task completion and quality

Status Indicators:
🟢 WORKING  - Team actively processing tasks
⚪ IDLE     - Team waiting for tasks
🔴 BLOCKED  - Team blocked by dependencies
🟠 ERROR    - Team encountered an error

Coordination Controls:
• Auto-decompose: Automatically break down tasks estimated >60 minutes
• Visual verification: Require visual verification for UI-related tasks
• Notify on completion: Send notifications when tasks complete
• Pause teams: Temporarily pause all agent team processing
