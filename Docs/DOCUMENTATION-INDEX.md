## 🎯 Architecture Overview

### Layers

```
┌─────────────────────────────────────────────┐
│        Vue.js Frontend (UI/UX Phase)        │
│  Components → Stores → Composables → APIs   │
├─────────────────────────────────────────────┤
│      Laravel Backend (Database Phase)       │
│  Controllers → Services → Models → Database │
├─────────────────────────────────────────────┤
│   Task Metadata (Schema Phase)              │
│  YAML Format → Parser → Database Storage    │
└─────────────────────────────────────────────┘
```

### Integration Points

1. **Frontend ↔ Backend:** REST API (Inertia.js bridge)
2. **Backend ↔ Database:** Eloquent ORM (22 models)
3. **Task Schema ↔ Database:** Task Model (task_metadata field)
4. **Frontend ↔ State:** Pinia Stores (Task, Project, UI)
5. **Components ↔ State:** Composition API (useTaskStore)
